# System Manual

Operation, safety, service, and maintenance documentation for the complete MARS RC Robot System.

## Files

- [MARS_RC_Robot_System_User_Manual.pdf](MARS_RC_Robot_System_User_Manual.pdf): printable user manual.
- [USER_MANUAL.html](USER_MANUAL.html): browser-readable user manual.
- `latex/MARS_RC_Robot_System_User_Manual.tex`: editable LaTeX source.
- `assets/`: source diagrams, screenshots, and photographs used by the manuals.
- `latex/assets/`: PDF and raster assets prepared for the LaTeX build.

Use the PDF or HTML file for normal operation. Edit the LaTeX and source assets only when maintaining the manual.
